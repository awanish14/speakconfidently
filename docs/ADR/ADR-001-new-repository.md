# ADR-001: New Repository

## Decision

SpeakConfidently is implemented from a new repository rather than forked from an existing language-learning project.

## Reason

Existing projects are valuable references but have different product goals, architectures and licensing constraints.

Our core product intelligence—evidence, patterns, learner model, intervention and retest—must have a clean ownership boundary.

## Consequence

We may reuse mature libraries and components after license review, but the product architecture is ours.
