# SpeakConfidently — Product Flows

## Flow 1: Onboarding

Goal → target language → approximate level → speaking context → consent → diagnostic conversation.

## Flow 2: Diagnostic

The AI says, in effect:

“Let's just talk. Don't worry about mistakes. I'll learn how you speak.”

The system should collect evidence without making the learner feel tested.

## Flow 3: Normal conversation

1. Choose free talk or scenario.
2. Learning planner selects an objective.
3. AI starts conversation.
4. User speaks.
5. Speech and language systems analyse asynchronously where possible.
6. Conversation continues naturally.
7. Session ends.
8. Analysis completes.

## Flow 4: Feedback

Show a small number of high-value findings.

For each:
- what you said
- what was better
- why
- example
- confidence/evidence where relevant
- practice action

## Flow 5: Practice

Practice should use the learner's own recurring issue in varied contexts.

Example:
- teach “for” vs “since”
- controlled example
- guided response
- free response

## Flow 6: Retest

A future conversation should naturally create an opportunity to use the target skill.

The learner should not necessarily be told:

“Now I am testing your present perfect.”

The system evaluates spontaneous use.

## Flow 7: Progress

Show:
- recently improved
- recurring patterns
- strong skills
- pronunciation targets
- recent evidence
- comparison with earlier conversations

Avoid gamification as the primary proof of learning.
